## そのまま使えるプロンプト

```
保護者向けのお便りの下書きを作ってください。
伝えたいこと：
・（例：来週から水泳の授業が始まる）
・（例：水着・タオル・水泳カードを持たせてほしい）
・（例：体調が悪い日は、カードに記入してほしい）
読む人：小学（学年）年の保護者
長さ：300字程度
文体：やさしく、丁寧に
```

## 学級通信なら

```
学級通信の「今週のできごと」のコーナーを書いてください。
できごと：（例：社会科見学でパン工場に行った。子どもたちは大きな機械に驚いていた）
雰囲気：子どもたちの様子が伝わる、あたたかい文章で
長さ：200字程度
```

## 仕上げ

[コツ5](/guide/15-aikusasa/)のとおり、外に出す前に**AI臭さを消して、自分で読み直します**。

```
かたい決まり文句や、同じ言い回しの繰り返しを直して、先生が保護者に話すような言葉にしてください。
```
