所見を何十人分も書いていると、「意欲的に」「積極的に」など、同じ言葉ばかりになりがちです。AIは、**言い回しのバリエーションを出す**のが得意です。

## そのまま使えるプロンプト

```
通知表の所見の下書きを作ってください。
対象：小学（学年）年の「生徒A」
よかったこと・がんばったこと：
・（例：算数の時間に、自分の考えを図にして説明できた）
・（例：係の仕事を最後まで責任をもってやりとげた）
・（例：友だちが困っているときに声をかけていた）
文字数：（例：150字程度）
保護者に伝わる、あたたかい言葉で書いてください。足りない情報があれば、先に質問してください。
```

## 仕上げの一言

```
AIっぽい決まり文句を消して、先生が書いたような自然な文章にしてください。
```

```
「意欲的」「積極的」を使わずに、別の言い方にしてください。
```

## 注意すること

- **実際の児童の名前・成績・家庭の様子は入れない**でください
- AIの文章はたたき台です。**最終的な所見は先生が書きます**
- 学校によっては、所見へのAI利用にルールがある場合があります。先に確認してください
