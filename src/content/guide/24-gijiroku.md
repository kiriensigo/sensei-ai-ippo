## そのまま使えるプロンプト

```
次の会議メモを整理してください。
「決まったこと」「担当」「期限」「次回までの宿題」に分けて、箇条書きにしてください。

（ここに会議メモを貼る）
```

続けて、共有用の文章も作れます。

```
この内容を、教職員に共有するための200字程度のメール文にしてください。
```

## 録音・文字起こしから作る

オンライン会議のツールには、録音や文字起こしから自動で議事録を作る機能があるものもあります。使える機能はプランや学校の設定で違うので、確認してみてください。

## 注意すること

- **児童生徒の個別の情報を含む会議**（ケース会議など）の内容は入れないでください
- 学校のルールで、会議の内容を外部のAIに入れてよいかを確認してください
