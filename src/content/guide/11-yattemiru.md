AIを使い始めた人が一番つまずくのは、「何をどう頼めばいいかわからない」ところです。

でも、**最初から上手に頼む必要はありません**。

## 何を聞けばいいかわからないときは

AIは、**気軽に何でも聞ける助手**です。「こんなこと聞いていいのかな」と考えなくて大丈夫です。

まずは、ふだん**面倒だと思っていること**を、そのまま「できる？」と聞いてみましょう。

```
毎週の学年だよりの下書きを作るのが面倒です。手伝ってもらうことはできますか？
```

```
会議のメモを整理するのが苦手です。何か手伝えることはありますか？
```

「できますよ。こんな情報をください」と返ってきたら、それに答えるだけで進みます。

## 断られても、2回くらいは言ってみる

AIは、ときどき「それはできません」「わかりません」と返してくることがあります。でも、**言い方を変えると、あっさりできることもよくあります**。1回で諦めず、2回くらいは頼み直してみましょう。

```
では、全部でなくていいので、できるところだけ手伝ってください。
```

```
やり方を変えて、もう一度やってみてください。
```

それでも難しいときは、本当に今のAIには向いていないのかもしれません（[AIが苦手なこと](/guide/31-nigate/)）。数か月後に、もう一度試してみてください。

## 頼むときは、一言でいい

```
小テストを作って
```

これだけでも、AIは何かしら作ってくれます。

## 出てきたものを見て、直す

結果を見て、気になったところを、そのまま伝えます。

```
もっとやさしい問題にして
```

```
1問ずつ、ひとことヒントを付けて
```

```
10問から5問に減らして
```

AIとのやりとりは、**会話を続けながら直していくのが普通**です。1回で完成させようとしなくて大丈夫です。
