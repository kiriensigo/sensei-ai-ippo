AIを使い始めた人が一番つまずくのは、「何をどう頼めばいいかわからない」ところです。

でも、**最初から上手に頼む必要はありません**。

## まずは一言で

```
小テストを作って
```

これだけでも、AIは何かしら作ってくれます。

## 出てきたものを見て、直す

結果を見て、気になったところを、そのまま伝えます。

```
もっとやさしい問題にして
```

```
1問ずつ、ひとことヒントを付けて
```

```
10問から5問に減らして
```

AIとのやりとりは、**会話を続けながら直していくのが普通**です。1回で完成させようとしなくて大丈夫です。
