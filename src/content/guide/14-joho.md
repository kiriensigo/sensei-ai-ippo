AIは、こちらの状況をまったく知りません。**最初にどれだけ情報を渡すかで、結果が大きく変わります。**

## 比べてみる

**情報が少ない頼み方**

```
小テストを作って
```

**情報をしっかり渡した頼み方**

```
小学3年・算数・わり算（あまりなし）の小テストを10問作ってください。
授業の最後の5分で使います。
計算が苦手な子もいるので、前半はやさしい問題にしてください。
答えも付けてください。
```

後の方が、そのまま授業で使えるものに近づきます。

## 伝える4つのこと

| 項目 | 例 |
|---|---|
| だれに | 小学3年生、保護者、同じ学年の先生 |
| 何のために | 授業のふり返り、行事のお知らせ |
| どんな条件で | 5分で終わる、300字以内、やさしい言葉で |
| どんな形で | 10問の小テスト、箇条書き、表 |

## 資料を渡すと、さらに良くなる

文部科学省の学習指導要領など、公開されている資料をAIに読み込ませて、「この内容に合わせて作って」と頼むと、ねらいに合ったものが出やすくなります。

教科書は、単元名やねらいなどの**要点を伝える**ようにします。本文をそのまま貼るのは、著作権と学校のルールを確認してからにしてください。

## うまくいかないとき

- **条件を足す**：学年・量・時間・形式
- **例を見せる**：「こんな感じの文章で」と見本を貼る
- **言い方を変えて**、もう一度頼む
