AIはとても便利ですが、**信用しきらない**のが基本です。次の5つだけは、必ず守ってください。

## 1. 個人情報を入れない

児童生徒・保護者の名前、成績、家庭の事情などは入力しません。

- 名前は「生徒A」「Bさん」のように置き換える
- 学校名や地域名も、必要がなければ入れない
- **お勤めの自治体・学校の生成AIのルール**を先に確認する

## 2. もっともらしい間違いを言う

AIは、自信満々に間違えることがあります。

- **数字・日付・固有名詞**は、必ず自分で確かめる
- 小テストの**解答**は、先生が確認する

## 3. 存在しないものを出してくる

実在しないホームページや、架空の研究データ、存在しない論文を出してくることがあります。

- URLは、自分で開いて確かめる
- 「〇〇の研究によると」と出てきたら、本当にあるか検索する

## 4. 評価の判断は先生がする

成績や評価の最終判断は、先生がします。AIは**下書きや整理の手伝いまで**です。

- 所見の下書き → OK
- 評定を決めさせる → NG

## 5. 著作権に気をつける

市販の教材や他の人の作品を、そのまま入れたり、真似させたりしないでください。教科書の本文や挿絵をそのまま使うのも避けます。

## 間違いを減らすコツ

**① 資料を渡して「この資料に基づいて」と頼む**

文部科学省の学習指導要領など、公開されている資料を渡すと、間違いが減ります。

**② AI自身に見直しをさせる**

```
今の答えに、間違いや、実在しないものが含まれていないか見直してください。
```

これを2〜3回くり返すと、精度がかなり上がります。それでも、**最後は先生の目で確かめます**。
