## 困ったときの3つの一言

**作る前に質問してもらう**

```
足りない情報があれば、作る前に私に質問してください。
```

**頼み方をAIに書いてもらう**

```
（作りたいもの）を作るためのプロンプトを書いてください。足りない情報は、先に質問してから書いてください。
```

**見直しをさせる**

```
今の答えに、間違いや、実在しないものが含まれていないか見直してください。
```

## 小テスト・ワークシート

```
小学（学年）年・（教科）・（単元名）の小テストを（問題数）問作ってください。
使う場面：（例：授業の最後の5分）
答えも付けてください。
```

## 所見の下書き

```
通知表の所見の下書きを作ってください。
対象：小学（学年）年の「生徒A」
よかったこと・がんばったこと：
・（箇条書きで3〜4個）
文字数：（例：150字程度）
保護者に伝わる、あたたかい言葉で書いてください。
```

## お便り

```
保護者向けのお便りの下書きを作ってください。
伝えたいこと：
・（箇条書き）
読む人：小学（学年）年の保護者
長さ：300字程度
文体：やさしく、丁寧に
```

## AI臭さを消す

```
かたい決まり文句や、同じ言い回しの繰り返しを直して、先生が保護者に話すような言葉にしてください。
```

## 会議メモの整理

```
次の会議メモを、「決まったこと」「担当」「期限」「次回までの宿題」に分けて、箇条書きにしてください。

（ここに会議メモを貼る）
```

## Excelのやり方を聞く

```
Excelで（やりたいこと）をしたいです。
表の形：（例：A列に名前、B列に点数、2行目から31行目まで）
パソコンが苦手な人向けに、どのセルに何を入力すればいいか教えてください。
```
