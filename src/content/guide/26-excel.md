## そのまま使えるプロンプト

```
Excelで、テストの点数表から平均点と最高点を出したいです。
表の形：A列に名前、B列に国語、C列に算数の点数。2行目から31行目までデータがあります。
パソコンが苦手な人向けに、どのセルに何を入力すればいいか教えてください。
```

## うまくいかないとき

```
教えてもらった式を入れたら「#DIV/0!」と表示されました。どうすればいいですか？
```

エラーの表示をそのまま伝えると、原因と直し方を教えてくれます。

## 注意すること

- **実際の成績データは入れないでください。** 表の形（何列目に何があるか）だけ伝えれば十分です
- 試すときは、「生徒A」「生徒B」のような架空のデータで練習しましょう
