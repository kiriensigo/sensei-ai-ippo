## そのまま使えるプロンプト

```
小学（学年）年・（教科）・（単元名）の小テストを（問題数）問作ってください。
使う場面：（例：授業の最後の5分）
子どもの様子：（例：計算が苦手な子もいる）
答えも付けてください。
```

## 直すときの一言

```
もっとやさしい問題を3問増やして
```

```
1問ずつ、ひとことヒントを付けて
```

```
文章題を2問入れて
```

```
A4のワークシートの形にして、名前を書く欄を付けて
```

## 注意すること

- **解答に間違いが混ざることがあります。** 答えは必ず先生が確認してください
- 市販のテストや問題集を、そのまま入れて作り直させるのはやめましょう
