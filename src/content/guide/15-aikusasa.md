AIの文章には、独特のかたさや、決まり文句があります。保護者向けのお便りなど**外に出す文章**で、AIが書いたとわかると、信頼が下がってしまいます。

## 直してもらう頼み方

```
かたい決まり文句や、同じ言い回しの繰り返しを直して、先生が保護者に話すような、やわらかい言葉にしてください。
```

## 自分らしくする

自分が以前に書いた学級通信などを見本として渡すと、文体を合わせてくれます。

```
次の文章は、私が以前書いた学級通信です。この文体に合わせて、さきほどのお便りを書き直してください。

（ここに過去の文章を貼る。児童の名前などは消しておく）
```

## 最後は自分で読み直す

AIに直してもらっても、**最後は自分の目で読み直して**、言い回しを整えます。そのクラス、その学校ならではの一言を足すと、ぐっと先生らしい文章になります。
