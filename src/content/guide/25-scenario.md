## そのまま使えるプロンプト

```
学習発表会のシナリオを作りたいです。
わかっていること：（例：3年生、5人グループ、発表時間5分、テーマは「地域のやさい」）
足りない情報があれば、作る前に私に質問してください。
```

AIからの質問に答えると、シナリオの第1稿ができます。

## 直すときの一言

```
2場面目を、もっとユーモアのある内容にしてください。
```

```
全員のセリフの量が同じくらいになるようにしてください。
```

```
3年生が言いやすい、短いセリフにしてください。
```

## ポイント

AIが作るのは、あくまで**第1稿**です。子どもたちの言葉やアイデアを取り入れて、一緒に作り上げていくのは先生の役割です。
