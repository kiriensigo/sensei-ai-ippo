## 操作がわからないときも、AIに聞く

パソコンの操作や、Excelの関数など、誰かに聞きたくなったときも、AIに聞けます。

```
Excelで、学年ごとの平均点を出したいです。パソコンが苦手な人向けに、手順を教えてください。
```

## プロンプトも、AIに書いてもらう

以前は「プロンプトエンジニアリング」という、頼み方の技術が話題になりました。でも今は、**細かい書き方を覚えなくても大丈夫**です。

頼み方がわからなければ、それもAIに頼みます。

```
保護者向けのお便りを作るためのプロンプトを書いてください。足りない情報は、先に私に質問してから書いてください。
```

AIからの質問に答えていくだけで、いいプロンプトができあがります。できたプロンプトで、本番のお便りを作ります。

## 頼み方を、AIに直してもらう

```
今の頼み方を、もっと良くするにはどうすればいいですか？
```

AIから改善案がもらえます。何度か使ううちに、自然と頼み方が上手になります。
